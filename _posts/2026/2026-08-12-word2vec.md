### Introduction

과거 자연어처리 시스템에서는 단어를 원자적인 단위로 여겼고, 단순히 단어 사전의 인덱스로만 처리하였기 때문에 단어 간의 유사도를 계산할 수가 없었다. 또한 통계 기반 N-gram 모델은 대규모 고품질의 Corpus가 필요하므로 다양한 시스템에서 한계가 존재했다.

이런 이유로 단어를 단순한 원자적인 단위가 아니라, 신경망 학습을 통해서 단어 자체를 벡터로 표현하고자 하는 시도가 이뤄졌지만 비선형 은닉층으로 인한 연산량이 매우 컸다는 문제가 존재했다. 하지만 2013년에 등장한 CBOW, Skip-Gram은 비선형 은닉층을 제거해 연산량을 매우 가볍게 만들고, 단어 자체를 벡터로 표현함으로써 벡터 연산과 유추를 할 수 있도록 해주었다. 일반적으로 Word2Vec이라 하면 이 CBOW와 Skip-gram을 말한다.

### Word2Vec이란?

가장 먼저 알아야 하는 것은 **분포 가설(distributional hypothesis)**이다.  
분포 가설이란 **비슷한 위치나 주변에 나타나는 단어는 뜻도 서로 비슷하다**는 자연어처리의 기본적인 가정이다. 예를 들어 "사과를 먹는다." "배를 먹는다." 라는 문장에서 '사과'와 '배'는 서로 동일하게 '를'과 '먹는다' 라는 주변 단어를 가지기 때문에 '사과'와 '배'는 서로 비슷한 의미를 가진다는 것이다. Word2Vec은 이러한 가설에서 시작해서 단어와 그 주변 단어를 통해 학습함으로써 해당 단어의 벡터 표현을 얻어내는 방법이다.  

Word2Vec은 크게 CBOW 모델과 Skip-gram 모델로 나뉜다. 이전에는 은닉층으로 인한 연산 병목이 컸다면 Word2Vec 모델은 단순히 Context 혹은 Target을 예측함으로써 학습하기 때문에 연산량이 매우 가볍다는 장점이 존재한다.  

![word2vec](/post_image/2026/0812/image.png)

위의 그림과 같이 **CBOW는 양방향 주변에 있는 단어(Context)를 바탕으로 현재 단어(Target)을 예측하는 모델**이다. 반면 **Skip-gram은 현재 단어(Target)가 주어졌을 때 양방향 주변에 있는 단어(Context)를 예측하는 모델**이다. 두 모델은 Target 혹은 Context를 예측함으로써 각 단어들을 고정된 임베딩 공간의 Vector로 표현할 수 있도록 데이터를 학습하게 되며 이를 **Word2Vec**이라 한다.  


#### CBOW
``` python
class CBOW(nn.Module):
    def __init__(self, vocab_size, D):
        super().__init__()

        self.embed = nn.Embedding(vocab_size, D)
        self.W2 = nn.Linear(D, vocab_size, bias=False)

    def forward(self, xs):
        embeds = self.embed(xs)
        hidden_sum = torch.mean(embeds, dim=0, keepdim=True)
        out = self.W2(hidden_sum)
        return out
```

CBOW의 Pytorch 구현은 위와 같다.  

모델은 임베딩 레이어를 가지며, N개의 Context가 들어왔을 때 각 단어를 임베딩 벡터로 변환 후 전체 평균을 구해 Linear 연산을 거쳐 Target을 예측하는 Vocab Size 크기의 Logit을 반환할 수 있도록 한다.


``` python
def make_data_cbow(window_size):
    datas = []
    for i in range(window_size, len(words)-window_size):
        center_word = word_to_idx[words[i]]
        context_words = words[i-window_size:i] + words[i+1:i+1+window_size]
        t = []
        for context in context_words:
            t.append(word_to_idx[context])
        datas.append((t, center_word))
    return datas
```

CBOW를 학습시키기 위한 데이터로는 Window Size를 지정하여 각 Target 별로 Context를 구한 후, Context의 집합(입력값)과 Target(정답)를 하나의 데이터로 묶어 저장한다.


#### Skip-gram
``` python
class SkipGram(nn.Module):
    def __init__(self, vocab_size, D):
        super().__init__()

        self.embed = nn.Embedding(vocab_size, D)
        self.W2 = nn.Linear(D, vocab_size, bias=False)

    def forward(self, x):
        embed = self.embed(x)
        out = self.W2(embed)
        return out
```

Skip-gram의 Pytorch 구현은 위와 같다.  

CBOW와 마찬가지로 임베딩 레이어를 가지며, Target이 들어왔을 때 Context를 예측하는 vocab_size의 Logit을 반환한다.

``` python
def make_data_skipgram(window_size):
    datas = []
    for i in range(window_size, len(words)-window_size):
        center_word = word_to_idx[words[i]]
        context_words = words[i-window_size:i] + words[i+1:i+1+window_size]

        for context in context_words:
            datas.append((center_word, word_to_idx[context]))
    return datas
```  

학습 데이터도 CBOW와 마찬가지로 window_size를 지정하여 Target(입력값)과 Context(정답)을 함께 하나의 Data로 묶어 저장하도록 한다.  


#### 학습과 임베딩 벡터  

학습의 경우는 CrossEntropy를 통해 학습된다.

``` python
for epoch in range(epochs):
    total_loss = 0

    for contexts, target in data:
        contexts_tensor = torch.tensor(contexts, dtype=torch.long)
        target_tensor = torch.tensor([target], dtype=torch.long)
        optimizer.zero_grad()

        # context를 통해 target 단어의 출현 확률 계산
        pred = model(contexts_tensor)

        # CrossEntropyLoss로 정답과 비교 후 Loss 계산
        loss = loss_fn(pred, target_tensor)
        loss.backward()
        optimizer.step()

        total_loss += loss.item()
```

위는 CBOW의 학습 예시이다.  

Context와 Target을 Tensor로 변환한 뒤 (이 때 context와 target은 단어의 인덱스 값이다.) 모델을 통해 logit을 계산한 뒤 CrossEntropy로 학습을 진행한다.  

이러한 과정을 거쳐 **최종적으로 모델이 가지고 있는 임베딩 레이어 각각의 행이 우리가 얻고자 했던 각 단어들의 Vector 표현**이 된다.


#### 벡터 연산

Word2Vec의 가장 큰 장점은 단어가 Vector로 표현되므로 벡터 연산을 통해서 단어 간의 유사도를 계산할 수 있으며, 특히 Analogy를 적용할 수 있다는 점이다.

예를 들어 *KING : MAN = ? : WOMAN* 에서 ?에 들어 갈 단어를 찾고 싶다고 가정해보자. 우리는 벡터 연산을 활용해서 ?에 들어 갈 단어를 찾아낼 수 있다! $vec('king') - vec('man') + vec('woman')$을 수행한 벡터 값과 가장 거리가 가까운 단어 벡터를 찾아내게 되면 $vec('queen')$이 나오며 결과적으로 우리는 관계성을 파악하고 ?에 들어 갈 단어를 찾아낼 수 있게 된다.  

이는 Word2Vec의 효율적인 학습과 더불어서 단어 간의 관계성을 파악하는데 있어서 매우 큰 장점이라고 볼 수 있다!

### Negative Sampling

하지만 기존 Word2Vec은 큰 병목이 하나 존재하는데, 이는 모델이 예측을 할 때 모든 단어들의 logit을 예측한다는 점이다. 이는 Vocab Size가 커질수록 연산 비용이 급격하게 커지기 때문에 비효율적이다. 이를 해결하기 위해서 Negative Sampling을 추가로 도입한다.

**Negative Sampling**은 전체 단어를 대상으로 점수를 계산하는 대신 1개의 정답 단어(Positive Context)과 $k$개의 오답 단어(Negative Context)를 뽑아서 이들이 정답인지 아닌지를 맞추는 이진 분류 문제로 단순화하는 방법론이다. Objective Function은 다음과 같다.  

$$\log \sigma({v'_{w_O}}^\top v_{w_I}) + \sum_{i=1}^k \mathbb{E}_{w_i \sim P_n(w)} \left[ \log \sigma(-{v'_{w_i}}^\top v_{w_I}) \right]$$

이를 설명하면 데이터를 수집할 때 $P_n(w)$ 라는 확률 분포에 따라 Negative Context를 추가로 선정한다. 이는 일반적으로 빈도수에 $3/4$ 제곱을 취해서 사용한다.

이 때 모델은 Input과 Output 총 두 개의 임베딩 레이어가 존재하며 제일 먼저 Target의 Input 벡터를 구한 후 이 후 Positive Context와 Negative Context의 Output 벡터를 구해 Dot Product를 진행함으로써 유사도를 계산해준다.  
그 후 Positive Context와의 유사도 점수를 올리고, $k$개의 Negative Context와의 유사도를 낮추도록 학습을 진행한다.  

복잡해보이지만 코드로 구현하면 직관적으로 확인할 수 있다.

``` python
class SkipGramNeg(nn.Module):
    def __init__(self, vocab_size, D):
        super().__init__()

        self.in_embed = nn.Embedding(vocab_size, D)
        self.out_embed = nn.Embedding(vocab_size, D)

    def forward(self, target, pos_context, neg_contexts):
        v_c = self.in_embed(target) # (N, D)
        u_pos = self.out_embed(pos_context) # (N, D)
        u_neg = self.out_embed(neg_contexts) # (N, K, D)
        pos_score = torch.sum(v_c * u_pos, dim=1) # (N,)
        neg_score = torch.bmm(u_neg, v_c.unsqueeze(2)).squeeze(2) # (N, K)
        return pos_score, neg_score
```

``` python
class LossFn(nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, pos_score, neg_score):
        # Score를 가져와서 Loss 계산!
        pos_loss = F.logsigmoid(pos_score)
        neg_loss = torch.sum(F.logsigmoid(-neg_score), dim=1)
        # Batch Size에 따른 평균 계산
        total_loss = -(pos_loss + neg_loss).mean()
        return total_loss
```

이를 통해 최종적으로 Target의 임베딩 벡터를 표현하는 in_embed를 단어들의 임베딩 벡터로 사용하게 되며, 전과 동일하게 벡터 표현을 얻어내면서 모델은 Vocab Size에 대한 Logit을 계산할 필요없이 주어진 참/거짓만 분류하면 되므로 매우 효율적으로 학습을 진행할 수 있게 된다.  

마지막으로 Negative Sampling 외에도 학습을 효율적으로 최적화하기 위해 'a', 'the', 'in' 같은 의미는 별로 없지만 빈도수가 높은 단어들을 훈련에서 일정 확률로 제외되도록 하는 Subsampling of Frequent Words이나, 단어 단위가 아니라 자주 등장하는 구문을 하나의 단어 단위로 묶어 버리는 Learning Phrases도 소개되었지만, 여기서는 크게 다루지 않고 넘어가겠다.

### Limitations

Word2Vec은 과거에 등장한 매우 중요하고 혁신적인 기술이었지만 여전히 한계가 존재하는데 바로 하나의 정적인 Vector라는 점이다.  

모든 단어들은 다양한 문맥에서 다양한 맥락(동음이의어)으로 활용된다. 하지만 Word2Vec은 단순히 임베딩 공간에 하나의 의미로써만 고정된다. 실제로 Word2Vec이 멋지게 유추를 해내고, 문맥을 이해하는 것처럼 보여도 실제로는 단순히 학습한 데이터에 따라 함께 유사한 단어들끼리 비슷한 공간에 배치해놓았을 뿐, 실제로 문장에서 문맥의 변화를 동적으로 반영할 수 없다.  

예를 들어 'bank' 라는 단어에서 '은행' 이라는 의미도 있지만 '강둑' 이라는 뜻도 존재한다. 하지만 Word2Vec은 하나의 의미만 나타낼 수 있으므로 둘 중 학습한 데이터에서 가장 빈도가 높은 의미로 수렴해버리거나, 두 개의 평균으로 나타나 이도저도 아닌 값이 되어버릴 수도 있다.  

이를 해결하기 위해 이후에는 BERT나 GPT와 같은 모델은 같은 단어더라도 주변 문맥에 따라 서로 다른 벡터 표현을 가지는 동적인 벡터 표현(문맥적 임베딩)을 주로 사용한다.
